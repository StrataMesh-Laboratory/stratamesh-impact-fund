# StrataMesh Impact Fund

**Live:** [fund.calhegasmorais.pt](https://fund.calhegasmorais.pt/)  
**Operator entity:** [AMCM ENI](https://github.com/amcmorais/amcm-eni)  
**Laboratory:** [StrataMesh-Laboratory](https://github.com/StrataMesh-Laboratory)

> The Fund does not attempt to replace GitHub as the record of software development.  
> It consumes publicly verifiable GitHub data, normalizes it, derives transparent statistics,  
> and adds the financial layer required to remunerate contributors.

## Principle

| Layer | Role |
|-------|------|
| **GitHub** | Evidence of contribution |
| **Fund** | Interpretation, transparency, pooled grants (EUR/USD) |

**V0 does not use:** STRATA · GDA · AI impact scores · autonomous on-chain settlement.

## Six jobs (V0)

1. Discover StrataMesh repositories  
2. Import GitHub contribution data  
3. Aggregate by contributor  
4. Generate comparable contributor profiles  
5. Let contributors claim profiles and register payout details  
6. Accept donations into a pooled fund and record/distribute grants  

## Phases

| Phase | Goal |
|-------|------|
| **1 — Explorer** | GitHub ingestion, profiles, statistics, snapshots (no money) |
| **2 — Registration** | GitHub OAuth claim, payout registration, privacy |
| **3 — Fund** | Donations, epochs, allocation methodology, payment provider |
| **4 — Verification** | CI/benchmark/milestone evidence, human review, impact *indicators* |
| **5 — Cryptographic transparency** | Epoch hashes, Merkle roots, optional StrataMesh anchor |

## Metrics (descriptive, not “value”)

Commits · PRs opened/merged · reviews · issues · additions/deletions · repositories touched · active weeks · merge rate  

Every public number should link back to GitHub source evidence.
