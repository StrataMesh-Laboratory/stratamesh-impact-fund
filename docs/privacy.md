# Privacy

## GitHub data

Public GitHub activity is public.  
The Fund aggregates what is already visible on GitHub for scoped StrataMesh repositories.

## Claiming a profile

- Authentication via GitHub OAuth / App  
- Stable key: **GitHub user id** (not login)  
- Contact email: **explicitly confirmed** by the contributor — not silently harvested for finance mail  

## Payouts

- No raw bank/card numbers in Fund databases  
- Payment provider holds tokenized recipient handles  
- Fund stores: `payout_provider`, `payout_recipient_id` (opaque), `status`  

## Donors

- Prefer provider-hosted checkout  
- Fund records amount, currency, epoch, provider reference, status  
- Do not publish private donor financial identity on public pages
