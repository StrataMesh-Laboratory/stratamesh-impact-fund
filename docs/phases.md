# Development phases

## Phase 1 — Explorer (current)

- GitHub ingestion (API sync + webhook record)
- Contributor discovery & profiles
- Repository pages / API
- Descriptive statistics (no money)

## Phase 2 — Contributor registration

- GitHub OAuth claim (stable `github_user_id`)
- Explicit contact email
- Payout registration (tokenized provider ids)
- Privacy controls

## Phase 3 — Fund

- Donations via regulated provider
- Funding epochs
- Versioned methodology + human-approved allocation
- Payment instructions & reporting

## Phase 4 — Verification

- CI / benchmark / milestone evidence
- Security contributions
- Human verification
- Impact *indicators* (not V0 “objective scores”)

## Phase 5 — Cryptographic transparency

- Immutable epoch datasets
- Hashes / Merkle roots
- Optional StrataMesh anchoring (fund remains independent)
